# docs/iso

Pasta para cópias locais da ISO 14064 e de normas relacionadas. Somente este README é versionado; o restante da pasta está no `.gitignore`.

As normas ISO são licenciadas para uso individual e não podem ser redistribuídas. Cada membro da equipe coloca aqui a própria cópia.

Sugestão de nomes de arquivo, para que as referências nos documentos funcionem igual para todos:

- `iso-14064-1.pdf` — quantificação e relato de emissões no nível da organização
- `iso-14064-2.pdf` — nível de projeto
- `iso-14068-1.pdf` — neutralidade de carbono
- `nbr-iso-14064.pdf` — norma brasileira

Agentes de código podem consultar esses arquivos quando presentes, mas o que for adotado deve ser registrado em `docs/metodologia-calculo.md`, com as palavras da equipe e sem copiar trechos da norma.
